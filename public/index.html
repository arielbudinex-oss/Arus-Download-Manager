Arus v1.0.0

A quiet download manager for Windows.

Arus downloads files, HLS, and DASH streams with a segment engine written in Rust. The engine runs on this PC and listens only on the local loopback address. Nothing is routed through a cloud service.

Privacy policy

Last updated 8 November 2026.

Local only

Arus is a desktop utility. Your downloads, history, and preferences stay on this PC.

What Arus stores

  • Download records (name, URL, folder, and progress) in state.json inside the app data folder.
  • Preferences such as folder, limits, theme, and density, in the same local file.
  • Lifetime counters for files, bytes, failures, and the first-run date shown on the dashboard.

Network access

  • Arus only connects to servers you ask it to download from or scan.
  • Referer, cookies, and user-agent values are forwarded only to the file host, so authenticated downloads keep working.
  • The engine listens on 127.0.0.1 and is not reachable from other machines.

Browser extension

  • The extension reads media URLs on the page you are viewing so it can offer capture.
  • Captured links and per-site overlay preferences live in Chrome extension storage on this PC.
  • Arus does not upload browsing data anywhere.

Clipboard and telemetry

  • Clipboard watching reads links locally and can be turned off under Behaviour.
  • There is no telemetry, analytics, account system, or cloud sync.
